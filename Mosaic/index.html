Help

Select a material to edit its layer. Left-click or drag to fill cells and clear higher layers at those cells. Select the base to reveal the background. Right-click clears only the selected overlay.

The app starts in Select mode. Later project switches and reloads retain the current tool. Choose a prop or actor to enter Place. A translucent preview follows the cursor. Left-click places copies. Right-click while placing returns to object selection. Choose a terrain swatch to paint terrain with a translucent texture preview. The highlighted swatch indicates the active mode. Escape cancels the active gesture and always returns to object selection, clearing palette highlights. In Select, Shift-click adds or removes an object. Drag empty space to select object pivots inside a box, or Shift-drag to add them. Drag a selected object to move the group. Delete or Backspace removes the selection. Escape in object selection cancels a drag, or clears selection when idle. Drag a corner handle on a single selected prop or actor to scale uniformly about its pivot. Multiple objects cannot be scaled together. The compact scale control shows absolute scale and percentage together, updating live while dragging. Percentage is relative to the scale at handle press. Click a handle without dragging to focus the absolute value. Edit either box and press Enter. The reset arrow restores the sequence default. Escape dismisses the control or cancels an active drag. Objects rotate about their pivots. Selected objects show a magenta crosshair with a dark border at each pivot. Crosshairs stay upright and the same screen size at every zoom. Actors have green square markers at their pivots and draw above props. Later placements within each category draw on top. Selection uses image rectangles, including transparent pixels.

Use the wheel to scroll. Hold Alt (Option on Mac) and use the wheel to zoom around the cursor. Drag with the middle mouse button to pan.

Edits autosave to the project's level.json. Ctrl/Cmd+S saves now. Ctrl/Cmd+Z undoes and Shift+Ctrl/Cmd+Z redoes. Reload Project picks up asset changes.

Layers composite from bottom to top. Terrain textures must be square, have identical dimensions, and be 64–4096 pixels per side in multiples of 64. Each whole texture repeats from the map origin at one texture pixel per world pixel. Texture edges must be seamless. Masks always cover 64×64 pixels.
