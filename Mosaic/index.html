Help

Select a material to edit its layer. Left-click or drag to fill cells and clear higher layers at those cells. Select the base to reveal the background. Right-click clears only the selected overlay.

The app starts in Select mode. Later project switches and reloads retain the current tool. Choose a prop image to enter Place. A translucent preview follows the cursor. Left-click places copies. Right-click while placing returns to prop selection. Choose a terrain swatch to paint terrain with a translucent texture preview. The highlighted swatch indicates the active mode. Escape cancels the active gesture and always returns to prop selection, clearing palette highlights. In Select, Shift-click adds or removes a prop. Drag empty space to select prop pivots inside a box, or Shift-drag to add them. Drag a selected prop to move the group. Delete or Backspace removes the selection. Escape in prop selection cancels a drag, or clears selection when idle. Props use their asset scale and rotate about their pivots. Selected props show a magenta crosshair with a dark border at each pivot. Crosshairs stay upright and the same screen size at every zoom. Later placements draw on top. Selection uses image rectangles, including transparent pixels.

Use the wheel to scroll. Hold Alt (Option on Mac) and use the wheel to zoom around the cursor. Drag with the middle mouse button to pan.

Edits autosave to the project's level.json. Ctrl/Cmd+S saves now. Ctrl/Cmd+Z undoes and Shift+Ctrl/Cmd+Z redoes. Reload Project picks up asset changes.

Layers composite from bottom to top. Terrain textures must be square, have identical dimensions, and be 64–4096 pixels per side in multiples of 64. Each whole texture repeats from the map origin at one texture pixel per world pixel. Texture edges must be seamless. Masks always cover 64×64 pixels.
