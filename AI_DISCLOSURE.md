# AI Disclosure

## Purpose

This document explains how AI is used in the project. It summarizes the kinds
of help AI provides without recording every conversation or task.

## Uses of AI

AI assists with:

- code reviews, implementation assistance, and debugging
- architectural guidance, conformance checks, and tradeoff analysis
- technical research, algorithm exploration, and development tooling
- drafting, refining, and reviewing documentation
- checking consistency between code, documentation, and architectural decisions
- test planning, validation, and edge-case identification
